All Services

Corelix supports all services available in Coolify's one-click catalog — over 250 pre-configured open-source applications ready for instant deployment. Service-specific documentation for less common services is maintained by the Coolify community.

Custom Template Sources

Need a service that isn't listed here? Corelix supports custom template sources — add any GitHub repository containing Docker Compose templates to extend this catalog with your own services.
