Installation

If you decide to go with Corelix Cloud, there's no installation required. Simply visit Corelix Cloud Registration to create an account and start using Corelix within minutes!

Below, you'll find instructions for installing the self-hosted version.

Self-hosted Installation​

Self-hosting Corelix involves two steps:

  1. Install the base Coolify platform on your server
  2. Install the Corelix enhanced addon on top of Coolify

Step 1: Install Coolify​

Quick Installation (recommended)
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | sudo bash

Run this script in your terminal, and the base Coolify platform will be installed automatically.

Note for Ubuntu Users

The automatic installation script only works with Ubuntu LTS versions (20.04, 22.04, 24.04). If you're using a non-LTS version (e.g., 24.10), please use the Manual Installation method below.

Before You Begin​

1. Server Requirements​

You need a server with SSH access. This could be:

  • A VPS (Virtual Private Server)
  • A Dedicated Server
  • A Virtual Machine (VM)
  • A Raspberry Pi
  • Or any other server with SSH access
Note

It's best to use a fresh server to avoid any conflicts with existing applications.

2. Supported Operating Systems​

  • Debian-based (e.g., Debian, Ubuntu — all versions supported, but non-LTS Ubuntu requires manual installation)
  • Redhat-based (e.g., CentOS, Fedora, AlmaLinux, Rocky)
  • SUSE-based (e.g., SLES, openSUSE)
  • Arch Linux
  • Alpine Linux
  • Raspberry Pi OS 64-bit

3. Supported Architectures​

  • AMD64
  • ARM64

4. Minimum Hardware Requirements​

  • CPU: 2 cores
  • Memory (RAM): 2 GB
  • Storage: 30 GB of free space
Heads up!

If you're running both builds and the platform on the same server, monitor your resource usage. High resource usage could make your server unresponsive. Consider enabling swap space or upgrading your server if needed.

Quick Installation (Recommended)​

1. Prepare Your Server​

  • Log in as the root user (non-root users are not fully supported yet).
  • Configure SSH and set up your firewall.
  • Ensure that curl is installed.

2. Run the Installation Script​

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
Tip

If you're not logged in as the root user, run the script with sudo:

curl -fsSL https://cdn.coollabs.io/coolify/install.sh | sudo bash

3. Access Coolify​

After installation, the script will display your URL (e.g., http://203.0.113.1:8000). Visit this URL to create your first admin account.

CAUTION

Immediately create your admin account after installation. If someone else accesses the registration page before you, they might gain full control of your server.

Step 2: Install Corelix Enhanced Addon​

Once Coolify is running, install the Corelix enhanced addon:

curl -fsSL https://raw.githubusercontent.com/amirhmoradi/coolify-enhanced/main/install.sh | sudo bash -s -- --install-addon

This script will:

  • Check prerequisites (root, Docker, Docker Compose)
  • Detect your Coolify installation at /data/coolify/source/
  • Pull the enhanced Docker image from GHCR
  • Create docker-compose.custom.yml for the addon
  • Set CORELIX_PLATFORM=true in .env
  • Restart Coolify with the enhanced features enabled
Local Build Option

If you prefer to build the image locally instead of pulling from GHCR:

curl -fsSL https://raw.githubusercontent.com/amirhmoradi/coolify-enhanced/main/install.sh | sudo bash -s -- --install-addon --local

Verify Installation​

Check that the addon is installed correctly:

curl -fsSL https://raw.githubusercontent.com/amirhmoradi/coolify-enhanced/main/install.sh | sudo bash -s -- --status

Manual Installation​

For those who prefer more control, you can install Coolify manually. Follow the Coolify manual installation guide for the base platform, then run the addon install script above.

Manual Addon Installation​

  1. Clone the Corelix enhanced repository:
git clone https://github.com/amirhmoradi/coolify-enhanced.git /tmp/coolify-enhanced
  1. Run the install script:
cd /tmp/coolify-enhanced
sudo bash install.sh --install-addon

What the Installer Does​

The base Coolify installer:

  • Installs essential tools (curl, wget, git, jq, openssl)
  • Installs Docker Engine (version 24+)
  • Configures Docker settings (logging, daemon)
  • Sets up directories at /data/coolify
  • Configures SSH keys for server management
  • Installs and starts Coolify

The Corelix addon installer:

  • Pulls the enhanced Docker image
  • Creates a Docker Compose override file
  • Enables enhanced features via environment variables
  • Runs database migrations for new tables
  • Restarts the platform with all enhancements active

If you get stuck at any step, feel free to open an issue on GitHub.
