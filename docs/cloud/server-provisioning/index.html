Server Provisioning

Corelix provisions managed servers on EU infrastructure so you can deploy applications without managing the underlying hardware. Servers are provisioned via Hetzner Cloud with Coolify pre-installed and configured.

How It Works​

When you add a server:

  1. Select a size — Choose CPU, RAM, and storage based on your workload.
  2. Select a region — Pick a data center location.
  3. Corelix provisions the server automatically:
    • Creates a cloud server with Ubuntu 24.04 LTS
    • Configures SSH access with a managed key pair
    • Applies firewall rules (only Coolify-required ports)
    • Installs and configures Coolify
    • Runs health checks
  4. The server appears in your dashboard, ready for deployments.

Provisioning typically takes 2–5 minutes.

Choosing a size

Small handles most side projects and small apps. Medium is suitable for production workloads with moderate traffic. Large and XL are for high-traffic applications, large databases, or running many services on one server.

Adding a Server​

  1. Navigate to Servers in the dashboard.
  2. Click Add Server.
  3. Select a size from the available options.
  4. Select a region from the dropdown.
  5. Click Provision and wait for the setup to complete.
  6. Once provisioned, the server status changes to Online and you can start deploying.

Server Monitoring​

Each server's detail page shows:

  • Status — Online, offline, or maintenance.
  • Resource usage — CPU, memory, and disk utilization.
  • Running containers — Applications, databases, and services.
  • Docker version — Installed Docker Engine version.
  • Proxy status — Traefik or Caddy reverse proxy health.

Scaling Your Infrastructure​

Vertical Scaling (Resize)​

Resize an existing server to a larger tier:

  1. Go to Servers and select the server.
  2. Click Resize.
  3. Choose the new size.
  4. Confirm. The server will restart with the new specifications.
Downtime

Resizing requires a server restart. Plan for a brief downtime window (typically under 2 minutes).

Horizontal Scaling (Add Servers)​

Add more servers to distribute your workload:

  • Deploy different applications on different servers.
  • Separate databases from application servers for better performance.
  • Use environment-based server assignment (e.g., production on Large, staging on Small).

Security​

Every provisioned server includes:

  • Firewall — Only required ports are open (SSH, HTTP, HTTPS, and Coolify management ports).
  • SSH keys — Managed key pairs with no password authentication.
  • Automatic updates — Security patches applied via unattended upgrades.
  • Encrypted backups — When configured with S3 storage and encryption enabled.

Custom Configurations​

Need servers with specifications beyond the standard tiers? Contact our sales team for custom configurations including:

  • Higher CPU/RAM specifications
  • Additional storage
  • Dedicated (non-shared) hardware
  • Custom networking requirements
