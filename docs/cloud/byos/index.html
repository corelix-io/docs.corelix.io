Bring Your Own Server (BYOS)

BYOS lets you connect your own servers to the Corelix platform. Deploy and manage applications through the Corelix dashboard while keeping full control over your infrastructure.

Team & Enterprise

BYOS is available on Team and Enterprise plans.

Why BYOS?​

BenefitDescription
Cost controlUse your existing infrastructure — pay only the platform fee, no server markup
Data sovereigntyKeep data on servers you own, in locations you choose
Provider flexibilityUse any cloud provider, bare metal, or on-premises servers
ComplianceMeet regulatory requirements for data location and infrastructure ownership
Hybrid deploymentMix managed Corelix servers with your own servers

Requirements​

Your server must meet these minimum requirements:

RequirementDetails
OSUbuntu 22.04 LTS or Ubuntu 24.04 LTS
Architecturex86_64 (AMD64)
RAM2 GB minimum (4 GB recommended)
Disk30 GB minimum
SSH accessRoot or sudo-capable user
NetworkPorts 22 (SSH), 80 (HTTP), 443 (HTTPS) open
DockerNot required — installed automatically during setup

Connecting a Server​

Step 1 — Generate the Install Command​

  1. Go to Servers in your dashboard.
  2. Click Add Server and select Bring Your Own Server.
  3. Copy the generated install command. It includes a unique token for your team.

Step 2 — Run on Your Server​

SSH into your server and run the copied command:

curl -fsSL https://app.corelix.io/install | bash -s -- --token YOUR_TOKEN

This command:

  • Installs Docker if not already present
  • Installs and configures Coolify
  • Registers the server with your Corelix account
  • Sets up secure SSH key-based communication

Step 3 — Verify Connection​

After installation completes (typically 2–3 minutes):

  1. Return to the Corelix dashboard.
  2. Your server appears in the Servers list with status Online.
  3. You can now deploy applications to this server.

Mixed Mode​

You can use both managed Corelix servers and BYOS servers in the same account:

  • Managed servers for production workloads where you want zero infrastructure management.
  • BYOS servers for development/staging, or workloads with specific infrastructure requirements.

Assign applications to specific servers when creating or configuring them.

BYOS Pricing​

With BYOS, you pay only the Corelix platform fee — there are no server costs from Corelix since you provide the infrastructure:

PlanPlatform FeeServer Cost
Team (BYOS only)€49/mo per seat€0 (your infrastructure)
Enterprise (BYOS only)Custom€0 (your infrastructure)

Managing BYOS Servers​

BYOS servers support the same features as managed servers:

  • Application, database, and service deployments
  • Automatic SSL certificates
  • Reverse proxy (Traefik or Caddy)
  • Container monitoring and logs
  • Environment variable management
  • Persistent storage volumes

What Corelix Manages​

  • Application deployments and builds
  • SSL certificate provisioning and renewal
  • Reverse proxy configuration
  • Container orchestration
  • Backup scheduling (when configured)

What You Manage​

  • Server OS updates and security patches
  • Hardware/VM availability and uptime
  • Network configuration and firewall rules
  • Disk space monitoring
  • Server-level backups (outside of Corelix-managed backups)

Removing a BYOS Server​

  1. Stop all applications on the server.
  2. Go to Servers and select the server.
  3. Click Remove Server.
  4. The server is disconnected from Corelix. Docker containers and data remain on the server.

Removing a server from Corelix does not delete any data or containers from the server itself.
