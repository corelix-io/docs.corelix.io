MCP Server Free

Manage your Coolify infrastructure through natural language using AI assistants like Claude, Cursor, or VS Code Copilot.

Overview​

The Corelix Platform MCP Server implements the Model Context Protocol (MCP) — an open standard that lets AI assistants interact with external tools. It wraps all Coolify API endpoints as MCP tools, enabling commands like:

  • "List all my applications"
  • "Deploy the staging environment"
  • "Show me server resource usage"
  • "Create a backup schedule for the production database"
  • "Grant John deploy access to the Marketing project"

The server provides 148 tools covering servers, projects, applications, databases, services, deployments, backups, DNS, and more.

Prerequisites​

  • Node.js 18+
  • A Coolify instance with the API enabled
  • An API token (create in Coolify: Settings > Keys & Tokens > API tokens)

Quick Start​

No installation required — run directly via npx:

npx @amirhmoradi/coolify-enhanced-mcp

Client Configuration​

Claude Desktop​

Add to your claude_desktop_config.json:

{
  "mcpServers": {
    "coolify": {
      "command": "npx",
      "args": ["-y", "@amirhmoradi/coolify-enhanced-mcp"],
      "env": {
        "COOLIFY_BASE_URL": "https://coolify.example.com",
        "COOLIFY_ACCESS_TOKEN": "your-api-token"
      }
    }
  }
}

Cursor / VS Code / Kiro IDE​

Add to your MCP settings:

{
  "mcpServers": {
    "coolify": {
      "command": "npx",
      "args": ["-y", "@amirhmoradi/coolify-enhanced-mcp"],
      "env": {
        "COOLIFY_BASE_URL": "https://coolify.example.com",
        "COOLIFY_ACCESS_TOKEN": "your-api-token"
      }
    }
  }
}

Environment Variables​

VariableRequiredDefaultDescription
COOLIFY_BASE_URLYes—Your Coolify instance URL
COOLIFY_ACCESS_TOKENYes—API token with read/write/deploy scopes
CORELIX_PLATFORMNoauto-detectedForce enable enhanced tools
CORELIX_MCP_TIMEOUTNo30000API request timeout (ms)
CORELIX_MCP_RETRIESNo3Retry attempts for transient failures

Feature Auto-Detection​

The MCP server automatically detects whether Corelix is installed. If it is, enhanced tools are registered automatically based on enabled features. If not, only the 72 core tools are available — no configuration needed.

To force-enable enhanced tools (e.g., if auto-detection fails):

CORELIX_PLATFORM=true

Tool Safety Annotations​

Every tool includes safety annotations that help AI clients make decisions:

AnnotationMeaning
readOnlyHintTool only reads data, no side effects
destructiveHintTool may delete or irreversibly modify resources
idempotentHintRepeated calls with same arguments are safe

For example, list_applications has readOnlyHint: true, while delete_application has destructiveHint: true. AI clients use these to decide whether to ask for confirmation.

Example Conversations​

Deploying an application:

"Deploy my blog application" → AI calls list_applications, finds the blog, calls deploy with its UUID

Checking server health:

"How are my servers doing?" → AI calls list_servers and health_check, presents a summary

Managing permissions:

"Give Sarah deploy access to the Marketing project" → AI calls list_projects to find Marketing, get_team_members to find Sarah, then grant_project_access

Creating a backup:

"Set up daily backups for the production database at 2 AM" → AI calls list_databases, then create_resource_backup with a cron schedule

Retry & Error Handling​

The server automatically retries on transient failures:

  • HTTP 429 (rate limit) — retries with exponential backoff
  • HTTP 5xx (server error) — retries up to 3 times
  • Network errors — retries with increasing delays

All tool failures return descriptive error messages to the AI client.

Compatibility​

The MCP server works with:

  • Standard Coolify v4 (core tools only)
  • Corelix community edition (all tools)
  • Corelix cloud platform (all tools)
  • Enterprise/commercial deployments (all tools)
