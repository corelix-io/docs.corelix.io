Enhanced UI Themes Free

Choose from optional corporate-grade visual themes to give Coolify a polished, modern look.

Overview​

Enhanced UI Themes provides a multi-theme system with selectable visual themes that override Coolify's default styling. Themes are:

  • Disabled by default — Coolify looks exactly the same until you enable a theme
  • Instance-wide — the selected theme applies to all users
  • Admin-controlled — only owners and admins can change the theme
  • CSS-only — no structural changes to the UI, just visual styling
  • Self-hosted fonts — all fonts are bundled, no external CDN dependencies

Available Themes​

Linear-Inspired ("Enhanced")​

A clean, enterprise-SaaS aesthetic inspired by Linear's design language:

  • Deep neutral color palette with crisp borders
  • Focused accent usage for primary actions
  • Clean cool surfaces in light mode
  • Deep neutral layers in dark mode
  • Subtle transitions and hover effects

TailAdmin-Inspired ("TailAdmin")​

A polished admin dashboard aesthetic with the Outfit font family:

  • Professional sidebar and card styling
  • Refined typography with the Outfit font
  • Dashboard-optimized color palette
  • Clean data presentation

Enabling a Theme​

  1. Navigate to Settings in the sidebar
  2. Click the Appearance tab
  3. Select a theme from the Theme dropdown
  4. The theme applies immediately (reload the page to see full changes)

To disable a theme, set the dropdown back to None (default).

Admin Only

The Appearance tab is only visible to users with the Owner or Admin team role.

How Themes Work​

Themes apply CSS overrides scoped to a data-ce-theme attribute on the HTML element. This means:

  • Coolify's original styles remain intact underneath
  • Theme CSS only overrides specific properties (colors, borders, shadows, typography)
  • Light and dark modes are both covered
  • Removing the theme instantly restores the default look

Both Light & Dark Mode​

Each theme includes styling for both light and dark modes. Themes respect Coolify's existing dark mode toggle — you don't need to configure anything separately.
